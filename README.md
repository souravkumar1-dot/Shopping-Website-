# 🛒 My Shopping Website

A responsive e-commerce website built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- 👤 User Login & Signup
- 🏠 Home Page
- 🔍 Product Search
- 📂 Product Categories
- 🛍 Shopping Cart
- ❤️ Wishlist
- ➕ Increase/Decrease Quantity
- 💰 Coupon Discount
- 🧾 GST & Delivery Charge Calculation
- 💳 Checkout Page
- 📦 Order History
- 🌙 Dark Mode
- 📱 Responsive Design
- 💾 Local Storage Support
- ⭐ Product Details Page

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Font Awesome
